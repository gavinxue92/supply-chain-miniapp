# ADR-0003：单一配置切环境与统一图片地址拼接

**Status:** accepted
**Date:** 2026-11-20

## Context

微信小程序的请求必须是绝对 HTTPS 地址，而后端返回的主图、轮播、二维码和图文详情里的图片都是 `/api/v1/media/{id}` 形式的相对路径。开发、体验、生产环境的后端基址不同；图片还需要在微信公众平台配置 download 合法域名。若把地址散落在页面里，切换环境会遗漏并产生错误图片源。

## Decision

在单一配置模块中维护开发、体验、生产三套 API 基址，按构建模式或部署后缀选择；所有相对图片地址在请求与展示层统一与当前环境基址拼接。开发环境可在微信开发者工具中关闭域名校验；真机与生产必须使用 HTTPS，并配置 request 与 download 合法域名。

## Consequences

- 切换环境只改一处配置，页面与组件不感知环境差异。
- 上线前必须完成合法域名配置，否则真机请求与图片都会失败。
- 禁止在代码或数据中硬编码域名、客服联系方式与二维码地址。
