# ADR-0002：首页纳入一级分类、搜索与分类产品预览

**Status:** accepted
**Date:** 2026-11-20

## Context

仓库中已有的 `mini-program.md` 把 V1 定义为「不接入搜索、首页展示两级分类树、不做本地分页」。访谈先确定了：首页只放一级分类并在顶部提供搜索；搜索去独立结果页；产品列表一次取全量、本地分批渲染；点一级分类直接进该分类产品列表并在列表内提供二级筛选。之后用户要求初版按美团风格原型实现，原型首页除了图标入口还有双列产品卡片。需要把这两轮结论合成单一基线。

## Decision

现行 V1：首页展示一级分类、顶部搜索入口与分类产品预览；搜索结果进入独立页面且不传分类筛选；点一级分类进入该一级下所有启用二级分类的产品列表，列表内按 `categoryId` 本地筛选；列表一次请求完整数组，先渲染 20 条、触底追加 20 条。首页外观以 `prototype/index.html` 为准，属于初版视觉，后期可重设计（见 ADR-0004）。

分类产品预览的数据来源假设为：不新增后端接口，按现有分类树顺序请求分类产品接口，取少量产品合并展示。实现按此假设执行；若以后需要真实推荐接口，再另开 ADR 修改本决策。`mini-program.md` 降级为接口字段与后端规则参考，其页面与交互部分由规格覆盖。

## Consequences

- 推翻了旧文档的 V1 范围，后续实现与验收以新规格和原型为准，避免两份交互说明并存。
- 首页产品预览需要额外的分类产品请求与合并逻辑，但后端契约不变。
- 搜索纳入 V1，需要自行处理输入校验、防抖与旧响应覆盖新响应的竞态。
- 本地分批渲染只是前端展示策略，不是网络分页。
- 首页不再展示两级分类树，二级分类入口转移到产品列表页的筛选区域。
